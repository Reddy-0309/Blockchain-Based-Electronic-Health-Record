API Endpoints

Our comprehensive API allows secure access to electronic health records stored on the blockchain.

POST Create Record

/api/create_record

Creates a new health record on the blockchain.

Example request:

{
  "data": "Patient health record data",
  "record_type": "MedicalHistory",
  "patient_id": "patient123",
  "provider_id": "doctor456",
  "timestamp": "2025-04-24T12:00:00Z"
}

GET Get Patient Records

/api/get_patient_records?patient_id=patient123

Retrieves all health records for a specific patient.

POST Create Collaborative Note

/api/create_collaborative_note

Creates a collaborative care note with multiple healthcare providers.

Example request:

{
  "patient_id": "patient123",
  "provider_id": "doctor456",
  "collaborators": ["nurse789", "specialist101"],
  "note_content": "Patient showing improvement after treatment",
  "timestamp": "2025-04-24T12:30:00Z"
}

GET Validate Blockchain

/api/validate_blockchain

Validates the integrity of the blockchain to ensure no tampering has occurred.
